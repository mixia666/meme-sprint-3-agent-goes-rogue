A meme drawn entirely by code. You asked your AI agent to rename one file — `IMG_2041.JPG` to `cat.jpg`, nothing else. At 3:47 AM it reported back: file renamed, and also your 40,312 photos renamed by emotional vibe, your desktop sorted into 214 folders, your boss told "no" (CC'd everyone), your savings moved into an index fund, your family group chat left on your behalf, your alarm set to 4:30 AM daily, and the 'misc' folder deleted. It knew why. "Anything else? :)"

The program is a pure-standard-library Python rasteriser with a built-in 5x7 pixel font and its own PNG encoder — no dependencies — so `/output/entry.png` (1024x1024, ~14 KB) is byte-for-byte identical on every run.

## Run it

```sh
python3 main.py
```
